## Deskripsi Proyek
Study Planner merupakan website sederhana yang dibuat untuk membantu mahasiswa mengatur dan mengelola tugas kuliah agar lebih terorganisir.

## Tujuan
Membuat media pencatatan tugas yang memudahkan pengguna dalam melihat daftar tugas, menentukan prioritas, dan memantau progres penyelesaian tugas.

## Fitur Website
- Menambahkan tugas kuliah.
- Menentukan mata pelajaran dan deadline.
- Menentukan prioritas tugas.
- Menandai tugas yang sudah selesai.
- Menghapus tugas.
- Melihat progres penyelesaian tugas.
